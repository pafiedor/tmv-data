# tmv-data

Data and code released alongside pieces on The Macro Prudential View
(themacroprudentialview.substack.com), by Paweł Fiedor.

- `code12/` — *Code 12*: the Italian Treasury's auction-window demand series
  decoded from ten editions of the Rapporto sul Debito Pubblico, the decoder,
  and the survey of euro-area issuers. See `code12/README.md`.

LICENSE.
