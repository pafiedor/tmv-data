# tmv-data

Data and code released alongside pieces on The Macro Prudential View
(themacroprudentialview.substack.com), by Paweł Fiedor.

- `code12/` — *Code 12*: the Italian Treasury's auction-window demand series
  decoded from ten editions of the Rapporto sul Debito Pubblico, the decoder,
  and the survey of euro-area issuers. See `code12/README.md`.
- `cayman/` — *The German Short in Grand Cayman*: the Cayman Islands Monetary
  Authority's "Portfolio Investments by Jurisdiction" tables 2015–2024 as
  extracted, the IMF Portfolio Investment Positions series for the Cayman
  reporter, the 2023–2024 reconciliation between the two, and the extraction
  code. See `cayman/README.md`.
- `sponsor/` — *The Sponsor of Last Resort*: the Federal Reserve's MMLF
  section 11(s) file with an own-family / other / unattributed classification
  of every pledged security, the classification script, and the reconciliation
  of every Form N-CR filed in the first half of 2020. See `sponsor/README.md`.
